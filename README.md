# Keyhaven downloads

Public installer releases for [Keyhaven](https://keyhaven.app), an offline-first password manager by Mico Lasola.

This repository contains published application binaries and signed updater metadata only. The Keyhaven application source is maintained in a private repository.

Choose the installer for your platform from the [latest release](https://github.com/Mixscoo/keyhaven-downloads/releases/latest).
